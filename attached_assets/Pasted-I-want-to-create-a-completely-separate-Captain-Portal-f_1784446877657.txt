I want to create a completely separate Captain Portal for my GEF website.

This is NOT an admin panel.

This is a secure Club Management Portal where every approved captain can only access their own club.

==========================================================
SYSTEM OVERVIEW
==========================================================

Every club has one captain account.

Captains log in using Email and Password.

After registration the account is NOT automatically activated.

Every new captain account enters a "Pending Approval" state.

The Admin must manually approve every captain before they can access the portal.

Until approval they cannot access anything.

==========================================================
REGISTRATION
==========================================================

Captain registration should ask for:

Name

Email

Password

Confirm Password

(Optional) Phone Number

DO NOT allow captains to choose their own club.

Instead:

After registration the account appears inside the Admin Panel.

The Admin selects which club that captain belongs to.

Example:

Captain:
John

Assign Club:
Moneyball FC

Approve

Only after approval can the captain log in.

==========================================================
PERMISSIONS
==========================================================

Captains must ONLY have access to THEIR OWN CLUB.

They must NEVER be able to access:

Other clubs

League management

Player database

Other club budgets

Other club transactions

Admin tools

Settings

Database

Admin Dashboard

Everything must be isolated.

If a captain belongs to Moneyball FC they should only ever see Moneyball FC.

==========================================================
BUDGET ALLOCATION
==========================================================

Every club has one Total Budget.

Example:

10,000,000

Captains CANNOT edit this number.

Only the Admin can change the Total Budget.

Captains can ONLY split the existing budget.

Example:

Total Budget

10,000,000

Transfer Budget

4,000,000

Wage Budget

6,000,000

The sum must ALWAYS equal the current Total Budget.

The captain can change the allocation.

Example

Transfer Budget

5,500,000

Wage Budget

4,500,000

Valid.

Example

Transfer Budget

8,000,000

Wage Budget

5,000,000

INVALID

because it exceeds the Total Budget.

Never allow allocation greater than the Total Budget.
