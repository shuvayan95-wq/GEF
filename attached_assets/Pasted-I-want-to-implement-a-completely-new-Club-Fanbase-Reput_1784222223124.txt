I want to implement a completely new "Club Fanbase & Reputation System" into my GEF (Global EFootball Federation) website.

This system must be fully integrated into the existing database, admin panel, club pages, standings and future features.

=========================
OVERVIEW
=========================

Every club in GEF must have a Fanbase.

The fanbase represents the total number of supporters that club has built over time.

This is NOT random.

Fanbase must grow or decrease realistically according to club performance, player performances, transfers, trophies and administrative actions.

This system must be fully editable from the Admin Panel.

The fanbase should become one of the biggest long-term progression systems in GEF.

=========================
STARTING FANBASE
=========================

Every new club begins with an initial fanbase assigned by the administrator.

Example:

10,000 Fans

The starting value must NOT be hardcoded.

The Admin should be able to manually assign any starting value.

=========================
FAN GROWTH
=========================

Fanbase should increase gradually.

Growth should never feel unrealistic.

Winning one match should never suddenly add thousands of supporters.

Instead, use small realistic increments.

Examples:

Draw
+25 to +75

Loss
-20 to -50

+400 to +800

+250

Player of the Week
+75

+40 each

Signing a star player
+100 to +500

Releasing a star player
-100 to -300

Long winning streak
Bonus growth

Long losing streak
Small decline

Every fan gain or loss should be recorded inside the system.

=========================

=========================

Inside the Admin Panel create a complete Fanbase Management section.
